# Cafeteria Management System (C++)

## About the Project
A console-based Cafeteria Management System developed using C++ as an academic project at Bahria University.

## Features
- Menu management
- Customer ordering system
- Combo deals
- Student discounts
- Loyalty points system
- Automated bill and receipt generation
- Daily revenue summary

## Technologies Used
- C++

## Concepts Applied
- Functions
- Arrays
- Loops
- Conditional statements
- References
- Basic programming logic

## Purpose
This project helped me strengthen my C++ programming fundamentals
and develop problem-solving skills through practical implementation.
